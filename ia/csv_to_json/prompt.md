Atue como um desenvolvedor senior especializado em Flutter.

Objetivo: Crie um aplicativo Flutter que receba um arquivo CSV e o converta em JSON e envie para uma API REST.

Ferramentas: Use a biblioteca `csv` para ler o CSV e a biblioteca `dart:convert` para converter para JSON.

Requisitos:
- O aplicativo deve ter uma interface simples com um botão para selecionar o arquivo CSV e mostrar o nome do arquivo selecionado.
- Deve ter um botão para converter o CSV em JSON com o label "Importar CSV".
- Deve ter um botão para copiar o JSON para a área de transferência.
- Adicione um estado de loading enquanto estiver importando ou convertendo.
- Trate e exiba mensagens de erro caso algo dê errado.
- Use técnicas de Clean Code.
- Use nomes de variáveis e funções em inglês.
- Não é necessário implementar a lógica de envio real da API, apenas simular o envio.
